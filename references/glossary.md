# 术语词典 — The Mom Test

- **The Mom Test（妈妈测试）**：一组"连你妈都无法对你撒谎"的提问规则——谈生活、问过去细节、少说多听。
- **坏数据（Bad data）**：好评、泛泛之谈、点子；看似有效实则会制造假阳性。
- **好评（Compliment）**：不付出任何代价的称赞，零信息量，常是想尽快脱身的信号。
- **泛泛之谈（Fluff）**：泛化声称（我通常/总是/从不）、未来时承诺（我会）、假设式也许（我可能）。
- **点子（Idea）**：对方给的功能需求/建议；要理解动机，但不要服从。
- **假阳性（False positive）**：误以为方向正确，导致超配资源。
- **Ego 问题（The Pathos Problem）**：暴露自己的投入与情感，使对方出于保护而说好话。
- **推销模式（Pitch mode）**：一旦开始介绍想法，对方就不再谈他的问题。
- **过早聚焦（Premature zoom）**：在确认问题是否重要前就追问其细节。
- **房间里的大象（Elephant）**：被忽视的、可能直接杀死生意的关键失败点。
- **产品风险 vs 市场风险**：前者=我造得出/长得大/留得住吗；后者=他们要吗/付吗/够多吗。
- **承诺（Commitment）**：对方付出代价（时间/声誉/金钱）以示认真。
- **推进（Advancement）**：对方在真实漏斗中前进一步。
- **三大货币**：时间、声誉风险、金钱。
- **僵尸线索（Zombie lead）**：持续见面说好话却从不下单。
- **earlyvangelist**：有需求、知有需求、有预算、且已自己凑方案的人。
- **客户切片（Customer slicing）**：细分到能指明"去哪找人"为止。
- **who-where 对**：一类人 + 一个可触达渠道。
- **VFWPA**：Vision / Framing / Weakness / Pedestal / Ask —— 邀约五要素。
- **顾问倒转（Advisory flip）**：心态从"找客户"改为"找顾问"，摆脱需求感。
