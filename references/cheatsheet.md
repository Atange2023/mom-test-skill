# 决策规则速查 — The Mom Test

| 能力 | 一句话规则 |
|---|---|
| 三条铁律（The Mom Test） | 谈他们的生活、问过去的细节、少说多听——你不提点子，对方就没法撒谎。 |
| 三类坏数据的识别与化解 | 好评挡开、泛泛拉回具体、点子下挖动机；三者都不付代价，所以都不算数据。 |
| 好问题 / 坏问题的判定与改写 | 意见一文不值、未来必是谎言——把"你觉得/你会不会/愿付多少"改成"你现在怎么做/上次何时/代价多少"。 |
| 关键问题、热爱坏消息与 3 个大问题 | 每场对话至少问一个能推翻你当前生意的问题；meh 比 wow 更有信息量。 |
| 先广后深与房间里的大象 | 先宽后窄、找到强信号再深入；把产品/市场/预算等所有失败点摊开，别只盯最有趣那个。 |
| 产品风险 vs 市场风险 | 先分清风险在产品还是在市场；纯产品风险无法仅靠对话验证，要更早、更不确定地动手做。 |
| 保持随意：把会议降级成聊天 | 把访谈降级成随意的聊天；越不正式越接近真相，越晚提到你的想法进度越快。 |
| 承诺与推进（三大货币） | 用时间/声誉/金钱三大货币索取承诺；对方放弃得越多，他的话才越可信。 |
| 会议成败判定与修复 | 会议非成即败；以"是否获得承诺或推进"判成败，失败常在结尾可救回。 |
| 客户切片：切到"谁 + 在哪找" | 好的细分是"谁+在哪找"；反馈互相矛盾说明细分还不够具体，继续切。 |
| 找到并约到对话（含 VFWPA 邀约框架） | 把"你去找人"变成"人来找你"；约人用 VFWPA——愿景/定位/示弱/抬举/求助，别提点子。 |
| 对话流程与笔记（会前/会中/会后） | 会前定 3 个大问题、会中两人分工、会后团队复盘；笔记要能检索且团队真的会看。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
